A composer recipe for getting started with SilverShop. This includes
`silvershop/core` and several of the major modules such as
`silvershop\shipping`, `silvershop\discounts` and more.

## Installation

To setup a shop and a blank Silverstripe Project

```sh
composer create-project silvershop/recipe myshop
```
